# 멍냥 성향 테스트

12문항으로 알아보는 강아지·고양이 성향 테스트입니다. 다시봄동물의료센터 검수.

👉 https://jwim0123.github.io/mungnyang-test/

## 유형 분류

4개의 축 × 양극 = 16가지 유형. 개·고양이 성격 연구(Feline Five, C-BARQ, Jones & Gosling 2005 등)에서 쓰는 차원을 가볍게 재구성했습니다.

| 축 | 글자 | 의미 |
|---|---|---|
| 사교성 | S (Social) / R (Reserved) | 낯선 사람·동물에게 다가가는지, 경계하는지 |
| 에너지 | A (Active) / C (Calm) | 늘 움직이는지, 느긋한지 |
| 대담함 | B (Brave) / W (Watchful) | 새로운 자극에 태연한지, 예민한지 |
| 애착 | D (Devoted) / I (Independent) | 보호자 바라기인지, 혼자서도 잘 지내는지 |

축마다 3문항씩, 더 많이 고른 쪽 글자가 유형 코드가 됩니다.

## 수정하는 곳 (`index.html`)

- `Q` — 강아지/고양이 문항
- `T` — 16유형 이름·설명·놀이·팁
- `CLINIC` — 병원 이름과 네이버 플레이스 링크

## 이미지

`images/` 폴더에 `종-유형코드.jpg` 형식으로 넣으면 결과 화면에 표시됩니다.

```
images/dog-SCBD.jpg
images/cat-SCBD.jpg
```

4:3 비율, 가로 800~1200px, 장당 300KB 이하 권장.

## 공유 링크

결과 링크는 `…/mungnyang-test/#dog-SCBD` 형식이며, 이 링크로 들어오면 해당 결과 화면이 바로 보입니다.

> 재미로 보는 테스트이며 의학적 진단이 아닙니다.
